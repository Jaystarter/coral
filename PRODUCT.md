# Product

## Register

product

## Users

Coral is used by senior engineers, AI platform builders, technical leads, and power users who run multiple local coding agents against real repositories. They are often monitoring long running work, switching between agent terminals, reviewing changes, coordinating teams, and debugging failures while their own development environment remains active.

## Product Purpose

Coral turns independent CLI coding agents into an observable local team. It provides isolated worktrees, tmux backed terminals, shared message boards, workflows, scheduled jobs, token tracking, history, and operational controls in one local dashboard. Success means the operator can understand what every agent is doing, intervene precisely, and trust that local state, credentials, and worktrees are represented clearly.

## Brand Personality

Composed, exacting, orchestral. Coral should feel like a serious operations room for AI engineering teams: deliberate, legible, technically premium, and calm under pressure. The interface should make powerful actions feel controlled, not chaotic.

## Anti-references

Do not make Coral look like a generic GitHub dark clone, neon AI dashboard, chat app, crypto terminal, gamer control panel, or soft SaaS landing page. Avoid decorative purple gradients, glass cards as a default style, emoji-heavy personality, identical card grids, hero metric tropes, and vague "AI magic" copy. The product should not obscure risk, state, or local execution details behind decoration.

## Design Principles

- Make orchestration observable: every surface should clarify agent state, worktree context, risk, and next action.
- Luxury through precision: premium means alignment, density control, reliable states, and carefully tuned contrast, not decoration.
- Local-first trust: the UI should make it obvious when actions run locally, use local credentials, or mutate real repositories.
- Calm hierarchy over noise: live terminals, boards, and controls compete for attention, so hierarchy must be deliberate and restrained.
- Power without ceremony: expert workflows should stay fast, keyboard-friendly, and dense, with onboarding available when needed.

## Accessibility & Inclusion

Target WCAG AA contrast for all text and controls. Preserve visible focus states, full keyboard access, reduced motion behavior, and clear non-color status cues. Motion should communicate state changes and never block task flow. Terminal and dashboard surfaces must remain readable during long monitoring sessions.
